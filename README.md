# Relatório Gerencial de Vendas - Power BI

## 📌 Descrição do Projeto
Relatório interativo desenvolvido no Power BI Desktop como parte do desafio da DIO. O objetivo é analisar o desempenho de vendas e lucros a partir do conjunto de dados *financials*.

## 📊 Estrutura do Relatório

### Página 1: Visão Geral de Vendas
* **Cartões de KPI**: Vendas Totais, Lucro Total e Unidades Vendidas.
* **Gráfico de Colunas**: Vendas Totais por País (*Country*).
* **Gráfico de Linhas**: Evolução de Vendas e Lucro por Ano.
* **Segmentador de Dados**: Filtro dinâmico por Segmento (*Segment*).

### Página 2: Análise Detalhada por Produto e Margem
* **Matriz**: Detalhamento de Lucro, Vendas, Unidades Vendidas e Descontos por Produto (*Product*).
* **Gráfico de Rosca**: Distribuição do Lucro por Segmento (*Segment*).
* **Segmentador de Dados**: Filtro dinâmico por País (*Country*).

## 🛠️ Tecnologias Utilizadas
* Power BI Desktop
* Linguagem DAX (medidas e agregações nativas)
* GitHub para documentação e versionamento
